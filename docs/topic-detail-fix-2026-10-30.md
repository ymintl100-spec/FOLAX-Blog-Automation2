# FOLAX 0.3.0-rc.11 — 상세 분석 창 사라짐·화면 이동 수정

‘상세 분석’이 페이지 맨 아래에 열리며 자동 스크롤한 뒤, 계정 연결 상태 알림이 운영 화면 전체를 다시 그려 상세 내용을 지우는 경로를 수정했습니다. 계정 연결 상태는 주기적으로 갱신될 수 있어 같은 작업을 반복하게 만들었습니다. 구버전 렌더러에서 이 순서를 실제 Electron DOM으로 재현했습니다.

## 변경

- 상세 분석을 목록 아래 대신 화면 중앙의 별도 창으로 엽니다. 창 안에서만 스크롤하며 배경 페이지를 강제로 이동하지 않습니다.
- 상세 창은 목록을 다시 그리는 영역 밖에 두어 작업 완료·추천 갱신 때도 유지합니다. 입력 중인 실제 경험, 플랫폼·이미지 선택, 경쟁 분석 메모와 창 내부 스크롤을 보존합니다.
- 연결 상태·확인 시각만 바뀐 계정 알림은 전체 화면 초기화를 하지 않습니다. 계정 목록/표시 정보가 실제 바뀔 때만 다시 불러오고, 늦게 도착한 이전 요청을 적용하지 않습니다.
- 열어 둔 후보 목록도 배경 갱신 때 접히지 않도록 유지합니다. 동일 주제의 명시적 상세 갱신에서도 입력과 펼침 상태를 보존합니다.
- 닫기 버튼과 Esc로 닫습니다. 계정/발행 대상 변경이나 다른 메뉴로 이동할 때에는 기존 계정의 상세 창을 닫습니다. 상세 창의 작업 상태·오류는 창 안에서도 표시합니다.

생성·검수·발행 로직과 데이터 저장 형식은 변경하지 않았습니다. 기존 계정·설정·원고·이미지·중단 작업 기록을 삭제하거나 초기화하지 않습니다. 본문 1,000~1,200자·이미지 최소 4장·태그 30개·연관성 검수·승인 절차는 유지합니다.

## 실행

1. 실행 중인 기존 앱을 완전히 종료합니다.
2. `FOLAX-Detail-Fix-Download.exe` 다운로드 도우미를 실행합니다.
3. `다운로드\BlogAuto-Windows\Naver-Blog-Automator-0.3.0-rc.11.exe`를 실행합니다.
4. ‘운영·추천 TOP 10’에서 ‘상세 분석’을 누릅니다. 중앙 창이 열리고 배경 화면은 이동하지 않습니다. 앱 상단 버전이 0.3.0-rc.11인지 확인하세요.

도우미는 다운로드·체크섬 검사·압축 해제 후 폴더를 열며 앱을 자동 실행하지 않습니다. Chrome 확장 0.3.21은 변경하지 않았으며 이미 해당 버전이면 갱신할 필요가 없습니다.

## 검증

자동 테스트 131개 통과. 연결 상태 알림이 화면을 다시 만들지 않는지, 작업 완료 후 상세 창·입력값이 유지되는지, 동일 주제 갱신의 입력/스크롤 보존, 다른 메뉴·발행 대상 변경 시 닫기를 확인했습니다.

격리된 Electron UI에서 구버전은 계정 알림 직후 상세 내용이 사라짐을 재현했습니다. 수정 버전에서는 상세 열기 전후 배경 스크롤 위치가 같고, 연결 알림 3회와 실제 작업 완료 이벤트의 목록 재렌더 뒤에도 상세 창과 동일 입력 DOM·경험 메모·플랫폼·이미지 선택·판단 근거·내부 스크롤이 유지됐습니다. 닫기와 Esc, 렌더러 오류 0건을 확인했습니다. 실제 계정·유료 AI 호출·게시 요청은 사용하지 않았습니다.

Windows x64 EXE를 빌드하고 패키지 소스·버전·다운로드 체크섬을 검증합니다. Windows GUI 자체는 이 환경에서 실행하지 않았습니다.
