# FOLAX 0.3.0-rc.9 — 주제 관련 태그 30개

새 글의 기존 Writer 응답에서 핵심 주제·본문에 실제 다룬 질문·조건·생활 상황·연관어를 중요도 순으로 30개 정리합니다. 무관한 인기어·지역·상표·인물·허위 치료효과·경험·홍보로 채우지 않도록 지시하고 기존 최종 검수에서 관련성을 함께 확인합니다. 앱은 표기 정리·중복·개수만 검사하며 의미 관련성을 기계적으로 보장하지 않습니다.

- 태그는 본문과 별도의 JSON tags 배열로 저장합니다. 글자수 1,000~1,200자에 포함하지 않고 본문 끝에 해시태그 목록을 붙이지 않습니다. 이미지 최소 4장과 이미지 배치 오류 보완은 유지합니다.
- #·공백·기호·유니코드 표기를 정리하고 중복을 제거합니다. 중요도 순서를 보존하며 30개 초과는 앞 30개만 사용합니다. 30자를 초과한 태그는 잘라 의미를 바꾸지 않고 제외합니다.
- 정상적으로 30개를 받으면 추가 AI 호출이 없습니다. 정리 후 부족하면 해당 Writer 원고마다 태그만 한 번 보완 요청합니다. 본문 품질 때문에 기존 한 차례의 Writer 수정이 필요한 경우에만 수정본의 태그를 다시 확인합니다. 본문·제목·출처·이미지 계획은 변경할 수 없고 원고 지문과 개수를 검증합니다. 관련어가 부족하면 무관한 단어로 채우지 않고 중지합니다.
- 태그 보완 실패 시 본문과 완료 단계는 보존합니다. 작업 이력 재시도에서는 조사·Writer 결과를 재사용하고 실패한 태그 보완만 다시 요청합니다. 태그 보완 토큰은 사용량에 합산하지만 본문 재작성 횟수로 계산하지 않습니다.
- 생성 미리보기와 원고·승인·발행 화면에 태그 목록·개수·복사 기능을 추가했습니다. 화면의 목록은 원고와 별도로 보관하며 기존 원고의 태그를 자동으로 채우거나 바꾸지 않습니다.
- 네이버는 최대 30개를 확장 발행 설정에 전달합니다. 티스토리는 플랫폼 제한에 맞춰 우선순위가 높은 앞 10개만 발행하고 후보 목록은 30개를 보관합니다. 네이버 임시저장은 기존 경로를 사용하며 게시 설정의 태그 입력과는 별도입니다.

## 설치·실행

1. 기존 앱을 완전히 종료합니다.
2. `FOLAX-Thirty-Tags-Download.exe` 다운로드 도우미를 실행합니다.
3. 다운로드와 체크섬 확인 후 `다운로드\BlogAuto-Windows\Naver-Blog-Automator-0.3.0-rc.9.exe`를 실행합니다. 도우미가 앱을 자동 실행하지는 않습니다.
4. 새 글을 생성하면 태그 30개를 정리합니다. 생성 본문 또는 원고 화면의 `주제 관련 태그`를 펼쳐 확인·복사합니다.

기존 계정·설정·원고·중단 작업 기록을 삭제하거나 초기화하지 않습니다. 기존 작업을 재개하면 저장 당시 설정과 태그를 유지합니다. 이미 0.3.21인 Chrome 확장은 다시 갱신할 필요가 없습니다. 실제 발행 전에는 기존 최종 승인 절차를 사용합니다.
