FOLAX Windows 통합판 0.3.0-rc.24.3

프로그램 전체 EXE와 Chrome 확장 폴더가 들어 있습니다.
기존 실행파일이나 패치, 분할 다운로드 도구가 필요하지 않습니다.

실행 방법
1. ZIP을 우클릭해 '모두 압축 풀기'를 선택하세요.
2. 폴더 안의 Naver-Blog-Automator-0.3.0-rc.24.3.exe를 실행하세요.
   ZIP 안에서 직접 실행하지 말고 먼저 압축을 완전히 풀어 주세요.
3. 같은 Windows 사용자 계정에서는 기존 앱 데이터를 그대로 사용합니다.
   이전 FOLAX 프로그램은 먼저 완전히 종료하세요.

Chrome 확장(처음 설치하는 컴퓨터)
1. Chrome 주소창에 chrome://extensions 를 입력하세요.
2. 개발자 모드를 켜고 '압축해제된 확장 프로그램을 로드합니다'를 누르세요.
3. 함께 들어 있는 Chrome-Extension 폴더를 선택하세요.
   manifest.json 파일이 바로 안에 있는 폴더입니다.
4. 확장 버전은 0.3.24입니다. 로그인 대기 수정은 이 새 확장에 들어 있습니다.
   기존 0.3.23을 계속 사용하면 수정이 적용되지 않습니다.
   이전 확장 설치 폴더의 파일을 새 Chrome-Extension 내용으로 교체했다면
   chrome://extensions에서 BlogAuto의 새로고침을 누르세요.
   설치 경로를 모르면 이전 BlogAuto 확장만 제거한 뒤 새 폴더를 로드하고,
   앱의 연결 코드를 입력해 해당 Chrome을 다시 연결하세요.
   네이버 로그인 쿠키나 Chrome 계정 프로필을 삭제할 필요는 없습니다.

Codex(처음 설치하는 컴퓨터)
기존 rc.24와 같이 Codex CLI 설치와 로그인이 필요합니다.
1. https://nodejs.org/ 에서 Node.js LTS를 설치하세요.
2. 새 명령 프롬프트에서 다음 명령을 실행하세요.
   npm install -g @openai/codex
   codex login
   codex login status
3. FOLAX를 다시 실행하고 Codex 연결 상태를 확인하세요.
프로그램 EXE 자체에는 Node.js를 따로 설치할 필요가 없습니다.
위 설치는 Codex CLI를 사용하기 위한 단계입니다.

변경 사항
- 로그인 후 블로그 홈으로 돌아온 경우 등록한 글쓰기 화면으로 복귀합니다.
- 새 편집기 탭이 열렸거나 이전 로그인 탭이 닫힌 경우 해당 탭을 확인합니다.
- 실제 편집기·계정 권한을 확인한 뒤 대기를 해제하고 확장 표시도 갱신합니다.
- 인증·보안 확인 화면과 기존 편집기의 원고는 건드리지 않습니다.
- 같은 로그인 리다이렉트가 반복되면 3회 복귀 후 원인 안내와 함께 중지합니다.
- 부분 수정의 고정 6개 문단 제한을 해결했습니다.
- 불필요한 정의·추상적 해설·같은 조언의 반복을 줄이도록 작성·검수 지침을 수정했습니다.
- 본문 공백 제외 1400~1600자, 태그 15개, 이미지 최소 4장 정책,
  자동 보완 합계 최대 5회를 유지합니다.
- 기존 원고는 원고 화면의 '현재 원고 쉽게 다듬기 · AI 1회'로 새 버전을 만들 수 있습니다.
  결과 확인·재검수·승인이 필요하며 이미 발행한 네이버 글은 자동 수정하지 않습니다.

데이터 안내
이 파일에는 개인 계정·비밀번호·로그인 세션·원고 데이터가 들어 있지 않습니다.
다른 컴퓨터에서는 앱과 확장을 설치한 뒤 Codex·블로그 로그인을 각각 진행하세요.
기존 PC 데이터는 이 ZIP만 복사한다고 이전되지 않습니다.

검증
rc.24.3 소스를 Windows용으로 패키징했습니다.
묶음 안의 SHA256SUMS.txt는 개별 파일의 SHA-256을 담습니다.
AI 응답 검증은 모의 응답을 사용했습니다. 실제 네이버 발행은 수행하지 않았습니다.
