로그인 확인 중 연결 코드 발급이 막히는 문제 수정

네이버에 로그인한 Chrome이 열려 있어도 앱에서 확장 연결이 끊긴 확인 작업을 계속 기다리면, '로그인 확인 중'과 '확장 연결 없음'이 함께 표시되면서 연결 코드 버튼이 비활성화됐습니다. 일부 대기 작업은 확장 응답이 없어도 종료되지 않았습니다.

- 로그인 확인 작업과 글 입력·발행 작업을 구분합니다. 확인 작업이 남아 있거나 확장 연결이 끊겨도 '확장프로그램 연결' 또는 '확장 다시 연결'에서 새 코드를 받을 수 있습니다.
- 코드 발급은 이전 로그인 확인만 종료합니다. 계정·Chrome 프로필·로그인 쿠키·원고·이미지·작업 이력은 삭제하지 않습니다. 실제 로그인·글쓰기 권한 확인은 새 연결 후 확장에서 다시 수행하며, 코드 발급만으로 로그인 완료 처리하지 않습니다.
- 확장이 받지 않은 확인 작업, 응답이 멈춘 확인 작업, 연결이 끊긴 로그인 대기를 정리하고 앱 화면에 상태 변경을 알립니다. 연결이 살아 있는 실제 로그인·추가 인증 대기는 유지합니다.
- 대기 취소와 재연결 시 화면의 이전 확인 동작도 종료합니다. 이전 동작이 뒤늦게 끝나면서 새 확인 상태를 지우거나 취소 오류를 계속 표시하는 일을 방지합니다.
- 글 입력·발행 작업 중에는 코드 발급과 코드 사용을 모두 차단합니다. 기존 발행 결과 불확실 기록과 자동 재발행 방지 동작을 보존합니다.

사용 방법

1. 기존 FOLAX 앱을 완전히 종료하고 통합 ZIP을 모두 풉니다.
2. Naver-Blog-Automator-0.3.0-rc.24.7.exe를 실행합니다.
3. 계정 카드에서 '확장프로그램 연결' 또는 '확장 다시 연결'을 누릅니다. 로그인 확인 중에도 코드를 받을 수 있습니다.
4. 해당 계정 Chrome의 BlogAuto 확장에 복사된 연결 코드를 입력합니다. 열린 Chrome의 네이버 로그인은 그대로 사용합니다.
5. 확장 화면에서 로그인·상태를 확인한 뒤 앱에서 작업을 시작합니다. Chrome 글쓰기 권한이 실제로 확인돼야 로그인 완료가 됩니다.

Chrome 확장은 0.3.24로 변경하지 않았습니다. 이미 0.3.24를 사용한다면 재설치할 필요가 없습니다. 기본 작성 요청, 약 2,000자 권장 분량, 태그 15개, 원본 이미지 참고 생성과 기존 중단 원고 재사용 기능도 포함합니다.

검증: 자동 테스트 312개 통과(실패·건너뜀 0). 실제 Electron 화면에서 연결이 끊긴 로그인 대기 상태를 재현하고 연결 코드 발급·이전 확인 종료·발행 중 재연결 차단을 확인했습니다. 연결·상태 응답은 로컬 시험용 확장 클라이언트로 검증했으며 사용자 PC의 실제 네이버 로그인이나 실제 발행은 수행하지 않았습니다.

Windows 통합 ZIP에는 전체 EXE, Chrome-Extension 폴더, 한국어 안내, 파일별 SHA-256이 포함됩니다. 이전 EXE·패치·다운로드 실행기가 필요하지 않습니다.
