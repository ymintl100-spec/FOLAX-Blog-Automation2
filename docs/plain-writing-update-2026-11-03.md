# FOLAX 0.3.0-rc.13 — 한 번 읽고 이해할 수 있는 글

보내주신 원고는 맞춤형/기성형 비교와 스트레칭 병행이라는 핵심에 비해, 연구를 해석하는 과정과 같은 주의점을 여러 부정문으로 설명하는 부분이 길었습니다. 해요체와 줄바꿈을 적용해도 읽는 사람이 다시 뜻을 풀어야 하는 문제를 작성·검수 기준에 반영했습니다.

## 새 글의 기본 기준

- 정보글은 첫 2~3문장에서 질문에 답합니다. 일상·경험 글은 제공된 실제 장면으로 시작하며 허구의 체험을 만들지 않습니다.
- 한 문장에는 핵심 뜻 하나를 담고 어려운 용어는 처음에 일상말로 풉니다. 소제목은 실제 독자의 질문·선택을 담고 짧은 문단으로 설명합니다.
- 연구 검토 절차·유형의 추상적 구분 대신 그 결과가 독자에게 어떤 뜻인지 직접 설명합니다. 필요한 조건은 관련 설명에 한 번 보존하고 같은 주의점을 여러 부정문으로 반복하지 않습니다.
- 분량을 채우려고 반복하는 대신 확보한 근거 안에서 필요한 이유·차이·조건을 구체화합니다. 근거 없는 효능·방법·횟수·경험은 추가하지 않습니다.
- 기존 Main 검수의 자연스러움·가독성 판정에서 실제 어려운 문장을 확인합니다. 줄바꿈이나 해요체만으로 통과시키지 않으며 기존 한 차례 Writer 보완에 쉽게 풀 방향을 묶습니다. 단어를 기계적으로 치환하거나 별도 가독성 모델·검색·학습 호출을 추가하지 않습니다.

본문 1,000~1,200자, 이미지 최소 4장, 태그 30개, 내부 연관성 검수와 이미지 생성 전 단계 수정은 유지합니다. 숫자·조건·예외·의학적 불확실성을 쉽게 쓴다는 이유로 삭제하거나 더 강한 결론으로 바꾸지 않습니다.

## 기존 저장 원고 쉽게 다듬기

‘원고·승인·발행’에서 저장 원고를 열고 **현재 원고 쉽게 다듬기 · AI 1회**를 누르세요. 화면에서 직접 고친 내용이 있으면 먼저 ‘수정본 저장’을 눌러야 합니다.

기존 자료·현재 원고·편집 기준으로 Writer 요청 한 번을 수행합니다. 새 조사나 이미지 생성은 하지 않습니다. 수정본은 새 버전으로 저장하고 원본 버전·소제목·이미지 삽입 번호/순서·이미지 경로·태그·내부 출처를 보존합니다. 숫자·연도·URL과 표식이 바뀌거나 분량 기준을 벗어난 응답은 기존 원고를 보존하고 중지합니다. 사용자가 모델 실행 오류의 재시도를 선택하면 그 호출은 별도 사용량에 포함됩니다.

수정본의 AI 검수와 이전 최종 승인은 해제됩니다. **현재 버전 AI 검수 요청 → 내용·이미지 확인 → 현재 버전 최종 승인** 순서로 진행하세요. 쉽게 다듬기는 의미가 같음을 자동으로 보장하거나 게시글을 자동 변경하는 기능이 아닙니다. 앱에 등록된 로컬 저장 원고를 편집하며 이미 공개된 네이버 글은 이 버튼으로 변경하지 않습니다.

## 보내주신 내용으로 본 표현 차이

아래는 보내주신 원고의 주장과 조건을 쉬운 말로 풀어 쓴 짧은 예시입니다. 새로운 의학 자료를 검증하거나 치료를 처방한 내용이 아닙니다.

- “제작 방식이 다르다는 사실과 통증에 더 유익하다는 결과는 별개의 문제예요.”
  → “발에 맞춰 만들었다고 해서 통증이 더 잘 줄어든다고 볼 수는 없어요.”
- 여러 문단에 걸친 유형 비교·병행 조건의 해석 설명
  → “맞춤형이 기성형보다 항상 더 좋다고 보기는 어려워요. 다만 기성 깔창의 연구에서는 스트레칭을 함께 했어요. 깔창만 썼을 때도 같은 결과가 난다고 받아들이면 이 조건을 놓치게 돼요.”

예시 문장을 다른 주제의 사실 근거로 쓰거나 사용자의 승인 문체로 자동 등록하지 않습니다. 실제 글은 해당 주제의 수집 근거와 사용자가 수정·승인한 문체를 함께 사용합니다.

## 설치·실행

기존 앱을 완전히 종료하고 `FOLAX-Plain-Writing-Download.exe` 도우미를 실행하세요. 다운로드 폴더에서 `Naver-Blog-Automator-0.3.0-rc.13.exe`를 실행합니다. 새 글에는 새 작성·검수 기준이 적용됩니다. 기존 원고는 자동 변경하지 않으며 쉽게 다듬기 버튼을 선택해 사용할 수 있습니다.

기존 계정·설정·원고·이미지·중단 기록을 초기화하지 않습니다. Chrome 확장 0.3.21은 변경하지 않았습니다.

## 검증

자동 테스트 144개 통과. 기존 Writer/Main 호출 한도 안의 가독성 보완, 수동 쉽게 다듬기 한 번의 Writer 요청, 새 수정본과 승인 해제, 원본·이미지 경로·표식·태그·내부 출처 보존, 잘못된 번호·연도·분량 응답 거절과 이전 버전 요청 거절을 확인했습니다.

격리된 Electron UI에서 실제 버튼을 눌러 Writer 한 번의 대체 응답으로 새 버전을 저장하고 원본·이미지·태그를 보존하는 경로와 렌더러 오류 0건을 확인했습니다. 모델 응답은 테스트용 대체 응답이며 실제 생성 문장의 가독성을 유료 모델로 평가한 것은 아닙니다. 실제 유료 AI·계정 발행·Windows GUI 실행은 수행하지 않았습니다. Windows x64 빌드·패키지 소스·버전·다운로드 체크섬을 검증합니다.
