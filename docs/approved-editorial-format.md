# 승인 원고 기반 편집 형식 기능 (2026-10-26)

## 목적
'발편한 생활노트'는 네이버 블로그 doctorkidney·yogawarm를 **문장이나 주제가 아닌 편집 형식**의 벤치마킹 대상으로 관리한다.

- doctorkidney: 직접 네이버 본문 접근이 제한되어 동일 운영자의 공개 브런치 칼럼에서 확인된 '일상적인 상황 → 핵심 메시지 → 설명 소제목 → 실제로 쓸 수 있는 정보' 구성을 참고했다. 의사 자격·진료 경험·그분만의 말투는 사용하지 않는다.
- yogawarm: 2026-10-26 현재 개별 본문 접근/검색 색인이 확인되지 않아 별도의 관찰 내용이나 구체적인 이미지·문단 규칙을 **추정하지 않는다**. 공개적으로 확인할 수 있는 개별 글 자료가 확보되면 양식을 다시 검토한다.
- FOLAX 직접 공개 글(운동화 깔창 교체 전 확인 사항)은 핵심 답변, 선택 기준, 조건별 확인, 필요할 때 체크리스트·FAQ·출처 등 편집 기준으로 참조한다.

외부에서 가져온 전체 문장이나 사진을 복제하지 않는다. 자동 글쓰기 품질이나 네이버 지수 상승을 보장하지 않는다.

## 사용법
1. 프로그램의 **계정 관리**에서 원하는 블로그 계정을 선택한다.
2. **최종 수정·승인 원고 (형식 참고용)** 칸에 운영자가 직접 수정한 최종 원고를 붙여 넣는다.
3. **이 글은 최종 검토·승인한 원고입니다** 체크를 선택한다.
4. **선택 계정 수정** 버튼으로 저장한다. 신규 계정은 **신규 추가**로 저장한다.
5. 다음 작업부터 해당 블로그의 Writer Agent가 형식 가이드를 활용한다. 글의 사실 검증·원본성·기존의 상업적 이해관계 고지는 유지한다.

### 데이터 보존
- 해당 원고는 로컬 계정 설정(account-categories.json)에만 저장된다. Git 커밋에는 사용자 원문이 포함되지 않는다.
- 프롬프트에는 원고 원문 대신 **소제목 수·문단 평균 길이·FAQ/체크리스트 존재 여부**만 전송한다. 수치는 편집 참고값이며 검색 상위 노출 공식이 아니다.
- 미승인 상태 또는 200자 미만의 원고는 적용하지 않는다.
- 원고를 수정하는 즉시 승인 체크가 해제된다. 변경한 원고를 다시 검토·승인한 후 저장한다.
- 사용자가 계정을 삭제하거나 자료를 지우도록 자동 강제하지 않는다. 기존 문서/카테고리/발행 자료는 유지한다.

## 범위 및 한계
- Writer Agent의 구성 기준과 Main Review Agent의 편집 검수 원칙이 변경된다.
- 기존 검색, 이미지 생성, 예약·발행 자동화 로직은 변경하지 않는다.
- 현재는 사람의 실제 내용 승인 상태를 **참고 원고에 대해서만** 확인한다. 프로그램이 생성한 모든 신규 글의 공개 발행을 별도 승인 게이트로 차단하는 기능은 이 변경에 포함되지 않는다.
- 자동화 프로그램 설치본은 GitHub 수정만으로 업데이트되지 않으므로 새 버전 빌드·설치가 필요하다.
