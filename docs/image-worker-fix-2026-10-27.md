# FOLAX 이미지 생성 오류 수정 — 0.3.0-rc.2

## 적용한 수정

PR #4의 두 커밋(26a74fc, 8185dec)을 모두 적용했습니다. 본문 이미지 프롬프트의 선언되지 않은 `options.formatGuidance` 참조를 명시적인 `formatGuidance` 입력으로 바꿨습니다. 실용형·설명형·가이드 미지정 회귀 테스트를 포함합니다. 이전 코드에서 `ReferenceError: options is not defined`가 재현됐고 수정 후 통과했습니다.

## 보존과 중단 원고 재사용

앱 ID, 제품명, 사용자 데이터 경로, 계정·설정·작업 이력·원고 DB 형식은 변경하지 않았습니다. 사용자 데이터 초기화나 마이그레이션은 추가하지 않았습니다. 기존 운영 기능을 포함한 0.3.0-rc.1 기반 업데이트입니다.

추가 테스트는 이미지 단계 실행 실패 → 체크포인트 파일 저장 → 설정·계정·이력 재로드 → 이력 재시도 계획 → 이미지 재개를 검증합니다. 조사·작성·검수 모델은 재호출하지 않으며 저장된 제목·본문을 그대로 사용합니다. 생성된 이미지가 일부만 있으면 완료 파일을 재사용하고 미완료 이미지만 요청합니다. 기존 계정·설정·원고·이력 및 체크포인트 파일이 바뀌지 않았는지도 검증했습니다.

사용자 PC의 실제 데이터에 접근한 것은 아닙니다. 재사용하려면 기존 사용자 데이터와 유효한 생성 체크포인트가 남아 있어야 합니다. 기록이나 파일이 삭제된 경우 복구를 보장할 수 없습니다. 이미지 확인과 기존 승인·발행 정책은 유지합니다. 기존 자동 발행 설정을 사용하는 계정은 재개 후 그 설정에 따라 진행되므로 실행 전 발행 설정을 확인하세요.

## 실행 및 재개 방법

1. 기존 BlogAuto/FOLAX 프로그램을 완전히 종료합니다.
2. `FOLAX-Image-Fix-Download.exe`를 실행합니다. 파일을 나눠 내려받고 SHA-256을 검증한 뒤 압축을 풉니다. 다운로드가 끊기면 같은 다운로드 도우미를 다시 실행합니다.
3. 열린 `다운로드\BlogAuto-Windows` 폴더에서 `Naver-Blog-Automator-0.3.0-rc.2.exe`를 실행합니다. 다운로드 도우미는 본 프로그램을 자동 실행하지 않습니다.
4. 기존과 같은 Windows 사용자로 실행합니다. 계정과 기존 원고·작업 이력이 표시되는지 확인합니다. 데이터 폴더를 삭제하거나 초기화하지 마세요.
5. 이미지 단계에서 중단된 것과 같은 계정·블로그·카테고리를 선택합니다. 보류 작업이 남아 있으면 `작업 시작`, 작업 이력에서 선택하면 해당 행의 `재시도`를 사용합니다. 기존 작업 취소를 누르거나 새 원고를 생성할 필요가 없습니다.
6. 로그의 `승인된 본문 재사용`과 `이미지 단계부터 재개` 메시지를 확인합니다. 기존 확장프로그램 변경은 이번 수정에 필요하지 않습니다. 생성된 이미지와 원고를 확인한 뒤 해당 계정의 승인·발행 절차를 따릅니다.

- 수정 전 PR 회귀 테스트에서 실제 참조 오류 재현, 수정 후 통과.
