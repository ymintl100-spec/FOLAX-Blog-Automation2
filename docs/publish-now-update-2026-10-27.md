# FOLAX 0.3.0-rc.5 — 지금 바로 발행

## 변경

기존의 모호한 `현재`·`지금` 표기를 `지금 바로 발행`으로 바꿨습니다. 원고 화면에서 공개 범위와 발행 시점을 선택하면 실제 실행 버튼도 `지금 바로 발행` 또는 `예약 발행`으로 표시합니다. 비공개·임시저장은 각각 저장 버튼으로 구분합니다. 예약을 선택할 때만 몇 시간 뒤 입력칸이 표시됩니다.

이미 준비한 예약 원고를 지금 발행으로 바꾸면 실제 요청도 현재 선택대로 다시 준비합니다. 이전 예약 설정이 남은 채 요청하지 않습니다. 화면을 다시 열면 준비한 공개 범위·예약 시점이 복원됩니다. 최종 승인·현재 제목 확인·원고 버전·이미지 변경 검사·중복 발행 방지는 유지합니다. 이미 실제로 등록한 예약글을 새로 게시하거나 네이버의 기존 예약을 취소하지 않습니다.

네이버 확장에서도 공개 즉시 발행은 편집기의 `현재` 시점을 직접 선택하고 확인합니다. 현재 선택을 확인할 수 없으면 예약 상태로 발행하지 않고 중지합니다. 이를 적용하려면 확장프로그램 0.3.20(편집기 20261027.1)을 새로고침해야 합니다.

기존 계정·설정·원고·작업 이력은 보존합니다. 본문 1,000~1,200자 설정, 상단 표기 제거 및 이미지 재개 수정도 유지합니다. 기존 예약 설정은 자동으로 즉시 발행으로 변경하지 않습니다.

## 설치

1. 기존 앱을 완전히 종료하고 `FOLAX-Publish-Now-Download.exe`를 실행합니다.
2. 다운로드·SHA-256 검사·압축 해제 후 열린 폴더에서 `Naver-Blog-Automator-0.3.0-rc.5.exe`를 실행합니다. 도우미는 앱을 자동 실행하지 않습니다.
3. 발행할 계정의 Chrome에서 `chrome://extensions`를 열고 BlogAuto의 새로고침(↻)을 누르세요. 다른 계정 Chrome의 새로고침은 해당 창에 적용되지 않습니다. 로그인 프로필을 삭제할 필요가 없습니다.
4. 확장이 계속 0.3.19라면 제공한 `BlogAuto-Extension-0.3.20.zip`을 별도 폴더에 압축 해제하고, 개발자 모드의 `압축해제된 확장 프로그램을 로드합니다`에서 내부 `extension` 폴더를 선택해 연결하세요. 새 앱의 확장 폴더와 다른 예전 폴더를 로드한 경우에 해당합니다.

## 즉시 발행

원고 화면에서 최종 승인한 글을 열고 `공개 범위: 공개` → `발행 시점: 지금 바로 발행`을 선택하세요. 현재 제목을 확인 입력한 뒤 `지금 바로 발행` 버튼을 누릅니다. 선택한 플랫폼 한 곳으로만 요청하며 새 원고를 만들지 않습니다. 비공개를 선택하면 공개 발행 대신 비공개로 저장합니다.

기존 작업 화면에서는 `공개설정: 전체공개` → `발행 시점: 지금 바로 발행`으로 설정을 저장할 수 있습니다. 승인 모드는 기존대로 최종 승인 단계에서 멈추며 승인 원고 화면에서 발행합니다. 이미 네이버에 등록한 예약글의 시각 변경·즉시 공개는 네이버 예약 관리에서 처리해야 합니다.

## 검증

자동 테스트 94개 통과. 준비된 예약을 지금 발행으로 전환, 예약 유지, 잘못된 제목·승인 없는 글·버전 변경·중복 발행 차단을 검증했습니다. 네이버 편집기 DOM 모의 테스트는 현재 시점 선택·검증 및 실패 시 중지를 확인합니다. Linux Electron 실제 화면과 IPC에서는 예약 복원·버튼 변경·예약 입력칸 숨김·즉시 요청을 검증했고, 발행 함수만 모의 처리했습니다. 실제 외부 발행 요청과 유료 모델 호출은 0건입니다.

Windows x64 EXE를 빌드하고 패키지 소스·버전·확장 버전 및 ZIP·분할 다운로드 체크섬을 검증합니다. 실제 Windows GUI와 로그인된 네이버 편집기의 최종 발행은 이 환경에서 실행하지 않았습니다.
