# 짧은 글로 운영하기: 100편 계측과 형식 v4

2026-10-23. 사용자 요청: 건강 정보와 일상·경험을 함께 운영하며, 참고 블로그의 내용이 아닌 형식을 참고한다. 문체는 사용자가 수정·승인한 글을 기준으로 한다. **본문이 너무 길다는 피드백을 우선하며, 공개 참고자료 목록은 생략한다.**

## 더 살펴본 범위

[doctorkidney](https://blog.naver.com/doctorkidney)와 [yogawarm](https://blog.naver.com/yogawarm)의 RSS 최근 50편씩, 총 100편의 공개 본문 HTML을 계측했다. 기존 40편에 60편을 추가했으며, 짧은 일상·생활 글 및 후기·모집 안내 12편의 전개를 별도로 다시 읽었다. [100편별 주소·측정값·재독 대상](blog-benchmark-100-samples.json)을 공개한다. 원문 전문·사진은 앱이나 문체 학습에 넣지 않는다. 기획·문체 적용에 추가 AI 호출은 없다.

본문과 인용 블록을 합한 공백 제외 길이의 중앙값은 각각 1,672.5자와 1,823자였다. 다만 표·사진·일부 캡션을 제외하고 자기소개·해시태그·본문 링크 등이 섞여 있으므로 앱의 글자수와 동일한 지표는 아니다. 참고 글이 모두 짧다는 결론이 아니다. **사용자의 분량 축소 요청에 맞춰, 관찰한 구성 방식을 더 좁은 질문과 짧은 글에 적용한다.**

HTML 구성·명시 스타일을 관찰한 조사다. 두 블로그 전체의 통계나 검색 성과와의 관계를 검증하지 않았고, 브라우저에서 원본 화면의 시각 비교를 완료하지 못했다. 의료 주장 자체를 모범 답안으로 취급하지 않는다.

## 이번 코드가 바꾸는 실제 기본값

| 글의 역할 | 목표 분량 | 허용 상한 | 소제목 상한 |
| --- | ---: | ---: | ---: |
| 건강 설명 | 약 700자 | 1,000자 | 3개 |
| 실행·루틴 | 약 850자 | 1,200자 | 3개 |
| 선택·비교 | 약 800자 | 1,100자 | 3개 |
| 일상·경험 | 약 450자 | 700자 | 2개, 없는 구성 가능 |

공백 제외이며 상한까지 채우라는 지시가 아니다. 수정·승인 글의 길이가 더 짧으면 목표를 조정하고, 길더라도 위 상한을 넘기지 않는다. 중요한 조건과 예외를 삭제해 줄이지 않고, 조사 단계에서 질문 범위를 좁혀 반복 배경·중복 결론을 덜어낸다. 앱은 내용을 잘라 붙이지 않으며, 길이·구성 실패는 기존 한 번의 Writer 보완 예산 안에서 수정한다.

기존에는 승인 글에서 줄·문단 길이와 짧은 발췌를 참고했다. 이제 **전체 글 길이·소제목 수·도입과 마무리 길이**도 집계해 기존 작성 호출에 전달한다. 수정 전후 비교와 승인 확인은 유지하며, 승인하지 않은 글이나 참고 블로그는 문체 예시가 되지 않는다. 계정별 저장과 2,500자 이내의 문체 문맥 예산을 유지한다.

참고자료·출처 목록은 작성 지시뿐 아니라 결과 정리, 모바일 미리보기, 네이버·티스토리 발행 입력에서도 제외한다. 예전 저장 원고에 목록이 있어도 발행할 때 제외한다. 내부 citations와 사실 검증은 유지하며, 본문 이해에 필요한 기관명·조건·협찬 공개·실제 관련 링크를 제거하지 않는다. 이미 게시된 글은 수정하지 않는다.

형식 v4와 짧은 분량은 **새 작업**부터 적용된다. 기존 재개 작업은 저장된 구성과 분량으로 이어가며, 원고를 자동 축약하거나 재생성하지 않는다. 새 앱은 `0.2.7-rc.2`, 확장은 `0.3.19`다.

## 확인 범위

자동 검증 54개가 통과했다. 분량 상한, 승인 자료의 전체 구성 집계, 내부 근거 연결 유지, 공개 참고자료 제거, 남겨야 할 본문 보존, 기존 호출 횟수와 재개 설정 보존을 확인했다. Linux Electron의 실제 미리보기와 IPC에서 승인·계정 격리·문체 설정·참고자료 미표시를 확인했고, Windows 배포 파일의 소스와 버전·네이티브 의존성을 검증했다. 실제 Windows 실행, 로그인된 네이버 편집기 입력·발행, 유료 AI를 사용한 완성 원고의 품질은 별도 실사용 확인이 필요하다. 화면 예시는 형식 검증용 자체 문구이며 실제 AI 생성 글로 표시하지 않는다.
