# 프로그램 내 Codex 설치·로그인

FOLAX Codex 설치·로그인 포함 통합 패키지 — 앱 0.3.0-rc.25 / Chrome 확장 0.3.23

프로그램 상단에 ‘Codex 설치·로그인’ 버튼을 추가했습니다. 새 Windows PC에서 Node.js를 별도로 설치하거나 CMD 명령어를 입력할 필요 없이 프로그램에서 설치를 진행할 수 있습니다. Codex를 사용할 수 있는 ChatGPT 계정의 로그인은 사용자가 직접 진행합니다.

새 PC에서 사용하는 순서
1. FOLAX-Codex-Setup-Download.exe를 실행합니다. 다운로드·검증·압축 해제 후 열린 폴더에서 Naver-Blog-Automator-0.3.0-rc.25.exe를 실행하세요.
2. 프로그램 상단 ‘Codex 설치·로그인’을 누릅니다.
3. ‘1. Codex 설치’를 누르고 설치 완료가 표시될 때까지 기다립니다. 공식 Node.js 24 LTS 파일을 내려받아 SHA-256을 검증하고 공식 npm 레지스트리에서 Codex CLI를 설치합니다. 인터넷 속도에 따라 몇 분 걸릴 수 있습니다.
4. ‘2. ChatGPT 로그인’을 누릅니다. 열린 로그인 창의 안내에 따라 브라우저에서 Codex 사용이 가능한 ChatGPT 계정으로 로그인하세요.
5. 프로그램으로 돌아와 ‘3. 상태 확인’을 누릅니다. 설치 완료와 로그인 완료가 각각 표시되면 창을 닫고 글 작업을 시작하세요. 로그인 창을 여는 것만으로 완료 처리하지 않습니다.

이미 Codex가 설치된 PC
기존 Codex 경로와 로그인 정보를 그대로 사용합니다. 설치 버튼은 비활성화되며 로그인·상태 확인만 진행하면 됩니다. 이미 로그인됐다면 추가 로그인은 필요 없습니다. 이번 기능을 위해 기존 Codex를 제거할 필요가 없습니다.

설치 방식과 데이터 보존
필요한 Node.js와 Codex는 프로그램의 사용자 데이터 폴더에 설치합니다. 관리자 권한·전역 npm 설치·시스템 PATH 변경은 필요하지 않습니다. 설치한 Codex의 실행 검증이 끝난 후에만 프로그램의 Codex 경로를 저장합니다. 실패하면 기존 경로·계정·원고·중단 작업 기록을 유지한 채 다시 설치를 시도할 수 있습니다. ChatGPT 비밀번호나 인증 키를 프로그램에 입력하지 않으며, 로그인 상태 명령의 원문 출력도 화면에 전달하지 않습니다.
설치 파일은 인터넷에서 내려받습니다. 오프라인 설치 패키지는 아닙니다. 다운로드·설치 실패 시 연결 상태와 폴더 쓰기 권한을 확인하고 다시 시도하세요. 글 작업이 실행 중일 때는 해당 작업이 끝난 뒤 설치·로그인을 진행하세요.

Chrome 확장도 같은 폴더에 포함
통합 다운로드에는 실행파일 옆에 압축 해제된 Chrome-Extension 폴더가 함께 들어 있습니다. 확장 ZIP을 따로 다운로드할 필요가 없습니다. 해당 계정 Chrome의 chrome://extensions에서 개발자 모드를 켜고 ‘압축해제된 확장 프로그램 로드’로 Chrome-Extension 폴더를 선택하세요. 이미 확장 0.3.23을 사용하고 있으면 이번 Codex 설치 기능 때문에 확장을 교체할 필요는 없습니다. 확장을 로드한 폴더는 이후 이동·삭제하지 마세요.

검증
자동 테스트 276개 통과(신규 14개). 실제 Electron 화면에서 미설치 → 파일 검증 실패 → 다시 설치 → 설치 완료 → 로그인 창 열기 → 상태 확인으로 로그인 완료 → 새로고침 후 설치 경로 유지까지 확인했습니다. 계정·설정·원고·작업 이력 보존과 인증 정보 미노출을 검증했습니다. 설치·로그인 처리는 격리된 모의 다운로드·실행·인증 응답을 사용했습니다. 공식 Node.js/npm 설치 정보의 접근도 별도로 확인했습니다. 실제 Windows에서의 설치·ChatGPT 브라우저 로그인은 사용자 PC에서 확인해야 합니다. 실제 네이버 글 발행이나 유료 AI 호출은 진행하지 않았습니다.

구현: codexSetup 서비스가 사용자 클릭에 따라 공식 메타데이터·검증 합계·Node ZIP을 가져오고, 독립 설치 폴더에서 npm을 실행합니다. npm 자체 모듈과 CLI 설치 prefix를 분리합니다. 기존 설치·인증 파일을 수정하지 않으며 설치 성공 후 codexCmdPath만 저장합니다. 앱이 설치한 CLI는 동봉한 node.exe로 셸 없이 실행하므로 Node가 전역 PATH에 없어도 본문·이미지 작업과 모델 목록 조회가 가능합니다. 새 IPC는 앱 창 발신자만 허용하며 임의 명령이나 URL을 받지 않습니다. 로그인은 고정 PowerShell 명령과 환경 변수로 경로를 전달한 별도 창에서 실행합니다.
