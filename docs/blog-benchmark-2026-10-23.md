# 건강 정보와 일상·경험을 함께 운영하기 위한 형식 벤치마크

관찰일: 2026-10-23, 한국 시간. 참고: [doctorkidney](https://blog.naver.com/doctorkidney), [yogawarm](https://blog.naver.com/yogawarm).

## 조사 범위와 한계

이전 6편에서 각 20편, 총 40편으로 확대했다. 두 RSS의 최근 50편씩에서 건강 설명·운동 루틴·선택/비교·식탁·일상·회고를 섞어 목적 표집했고, RSS 요약이 아닌 공개 본문 HTML을 수집해 구성 요소와 문장 전개를 확인했다. 표본 기간은 2026년 6~10월이다. [표본별 측정 자료](blog-benchmark-samples.json)에 주소·제목·종류·수치를 남겼다. 무작위 표본이나 블로그 전체의 통계가 아니며, 방문자·체류시간·검색 순위·전환율과의 인과관계를 확인한 조사는 아니다. 의료 주장 자체를 검증한 자료도 아니다.

공개 원문 전문과 사진은 앱·학습 자료·이 보고서에 재배포하지 않는다. 코드에는 일반화한 편집 기준만 넣고, 작성 호출 때 원문을 매번 수집하거나 40편을 프롬프트에 넣지 않는다. 브라우저로 전체 페이지를 시각 캡처하는 작업은 이 환경에서 완료되지 않았으므로 렌더링이 동일하다고 주장하지 않는다. 정렬·폰트·구성 수치는 본문 HTML에 명시된 속성을 기준으로 했다.

## 장기 운영을 위한 네 가지 글의 역할

### 1. 건강 설명: 걱정을 늘리지 않고 이해를 바꾸는 글

관찰 근거: [운동 강도에 관한 글](https://blog.naver.com/doctorkidney/224444553048), [식품 선택에 관한 글](https://blog.naver.com/doctorkidney/224446728850), [식욕과 생활 조건에 관한 글](https://blog.naver.com/doctorkidney/224403851635).

독자가 겪을 법한 구체적인 상황 → 자연스러운 질문 → 흔한 생각과 실제 조건의 차이 → 이유를 쉬운 말로 설명 → 생활에서 구분할 기준 → 처음의 고민에 대한 답으로 돌아오는 흐름이다. 핵심은 제목의 키워드를 반복하는 것이 아니라 독자의 해석이 한 번 바뀌게 만드는 것이다. 전문가의 진료 장면은 해당 작성자의 사실이므로 우리 글에 가져오지 않는다. 사용자 경험이 없으면 직접 체험을 주장하지 않는 일상 상황으로 도입한다.

### 2. 실행·루틴: 동작의 이름보다 따라갈 순서를 주는 글

관찰 근거: [하체 스트레칭](https://blog.naver.com/yogawarm/224450015368), [플랭크 접근 단계](https://blog.naver.com/yogawarm/224444337516), [재시작 루틴](https://blog.naver.com/yogawarm/224409815772).

상황과 대상 → 원리의 짧은 설명 → 준비/시작 자세 → 실제 움직임 순서 → 어려울 때 대안과 필요한 주의점 → 반복 가능한 마무리로 이어진다. 사진·움직임 자료가 해당 단계와 가까이 있다. 실행 설명을 효능 요약으로 대신하지 않는다. 횟수·각도·기간·의학적 효과는 형식을 채우기 위해 만들지 않고 실제 근거가 있는 범위만 쓴다. 동작마다 똑같은 긴 소개를 붙이지 않는다.

### 3. 선택·비교: 한쪽을 이기게 하기보다 같은 축으로 보는 글

관찰 근거: [요가와 필라테스 비교](https://blog.naver.com/yogawarm/224341920362), [건강식의 조건](https://blog.naver.com/doctorkidney/224429462492), [음식 조합과 양을 확인하는 글](https://blog.naver.com/doctorkidney/224348271428).

독자의 선택 상황 → 공통 비교 축 → 조건에 따른 차이 → 어느 쪽이 맞는지 달라지는 지점 → 내가 확인할 한 가지 순서다. A를 길게 설명하고 B를 짧게 덧붙이는 백과사전식 나열을 피한다. 수치를 비교하면 대상·단위·조건을 맞추고, 근거가 없는 우열을 만들지 않는다.

### 4. 일상·경험: 건강 정보를 살고 있는 사람의 목소리가 남는 글

관찰 근거: [여행 중 아침 기록](https://blog.naver.com/doctorkidney/224436323894), [직업 생활 회고](https://blog.naver.com/doctorkidney/224364045779), [육아와 나의 시간을 돌아보는 글](https://blog.naver.com/yogawarm/224405468799), [블로그 운영 회고](https://blog.naver.com/yogawarm/224450082575).

한 장면 → 그때의 생각/선택 → 작지만 구체적인 변화 → 지금 돌아보는 의미 → 첫 장면을 떠올리는 여운이 중심이다. 정보 글의 정의·원인·방법·결론 틀을 그대로 씌우지 않는다. 소제목 없이도 흐름이 성립한다. 이런 글의 신뢰는 실제 경험에서 나오므로, 사용자가 제공한 이번 글의 경험 메모가 있어야 1인칭 경험 글로 만들 수 있다. 문체 학습용 예시에 나온 경험은 새 글의 사실 자료로 재사용하지 않는다.

## 서로 다른 글에 같은 블로그의 목소리를 남기는 기준

- 건강 정보와 일상 글이 공통으로 지킬 독자의 기대는 '몸과 일상을 쉽게 이해하고 무리 없이 이어갈 선택을 돕는다'로 시작한다. 계정별 운영 방향은 사용자가 수정할 수 있게 한다.
- 설명형은 쉬운 이유와 조건, 일상형은 실제 장면과 선택이 중심이지만 문장 리듬·거리감·피할 표현은 같은 수정·승인 자료에서 배운다.
- 승인 자료의 첫 260자만 따라 하지 않는다. 실제 수정된 부분과 도입·중간·마무리의 짧은 발췌를 분산해서 참고하고, 문단·줄 길이의 대표값을 사용한다.
- 학습용 글을 편집한 것과 지금 발행할 원고를 고친 것은 구분한다. 무엇이 현재 글에 반영되는지 화면에 표시하고, 승인하지 않은 글·참고 블로그 전문은 문체 자료에 넣지 않는다.
- 모든 글이 같은 인사, 같은 번호, 같은 요약, 같은 댓글 요청으로 끝나지 않게 한다. 독자가 답할 내용이 있는 질문은 쓸 수 있으나 자동 문구로 붙이지 않는다.

## 그대로 따라 하지 않을 관찰점

표본 일부에서 제목의 시간 표현과 본문 안 재표제의 시간이 다르거나, 효과를 강하게 약속하는 표현이 보였다. 이는 모범 답안으로 취급하지 않는다. 제목·대표 이미지 문구·본문의 대상, 횟수, 시간, 범위를 기존 최종 검수에서 대조한다. 블로그 작성자의 자격, 환자 사례, 육아 경험, 수강생 반응, 내돈내산·협찬 관계를 사용자 사실처럼 옮기지 않는다. 인용이나 번호가 많다는 이유만으로 고품질 판정을 내리지 않는다.

## 이번 구현의 검증 기준

1. 같은 주제라도 설명·실행·비교·일상의 구성안이 달라야 한다. 자동 선택은 기존 조사 응답 안에서 하고 추가 형식 선정 호출을 만들지 않는다.
2. 일상형에 소제목 2개와 초반 정답을 강제하지 않는다. 실제 경험 메모 없이 1인칭 사례를 창작하지 않는다.
3. 짧은 줄과 빈 줄을 원고에서 모바일 미리보기와 확장 입력 계획까지 보존하며, 리듬을 조정해도 공백을 제외한 본문은 바뀌지 않아야 한다.
4. 승인 글의 수정된 중간·후반도 문체 지침에 포함될 수 있어야 한다. 무한히 프롬프트를 키우지 않고 발췌 예산을 유지한다.
5. 이미지가 항상 소제목 바로 뒤로 몰리지 않고 v3 원고에서 지정한 순서를 유지해야 한다. 이미지 생성 수 설정은 늘리지 않는다.
6. 형식 선택, 실제 사용한 승인 자료 수, 적용한 줄/문단 기준을 표시한다. 원고를 생성하지 않은 화면 예시를 실제 AI 생성 결과라고 부르지 않는다.
