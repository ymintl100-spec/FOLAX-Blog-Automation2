# rc.24.3 로그인 대기 복구

사용자는 같은 Chrome 창에서 trafle의 글쓰기 편집기를 열 수 있지만 앱은 로그인 대기, 확장은 ‘대상 블로그 글쓰기 화면으로 이동해 주세요’를 계속 표시했습니다.

기존 확장은 작업을 시작할 때 선택한 탭을 계속 검사했습니다. 로그인 후 블로그 홈으로 리다이렉트되면 ‘unknown’ 상태로 기다리고, 이전 로그인 탭이 남은 채 새 편집기 탭이 열려도 그 탭으로 전환하지 않았습니다. 새 글쓰기 화면을 준비하는 경로는 결과를 확장의 표시용 세션에 저장하지 않는 경우도 있었습니다.

수정된 확장 0.3.24는 로그인 대기 중에만 다음을 수행합니다.

- 알려진 읽기 전용 블로그 홈·게시글·네이버 홈에서 등록한 블로그의 글쓰기 주소로 복귀합니다.
- 새 탭의 대상 블로그 편집기를 실제로 확인한 경우 그 탭을 사용합니다. 이전 로그인 탭은 닫거나 이동하지 않습니다.
- 로그인 탭이 닫힌 경우 기존 대상 편집기를 찾아 확인합니다.
- 실제 확인 결과를 확장의 상태 표시에 저장하고 앱에 전달합니다.
- 같은 읽기 전용 리다이렉트가 반복되면 3회 복귀 후 원인 안내와 함께 중지합니다.

로그인이나 추가 인증을 완료했다고 가장하지 않습니다. 보안 확인·다른 계정·다른 블로그의 결과는 통과시키지 않습니다. 기존 편집기를 자동 이동하거나 그 안의 원고를 덮어쓰지 않습니다. Tistory 경로, 계정별 Chrome 저장 공간, 쿠키·로그인 정보와 발행 승인 절차는 유지합니다.

배포는 Windows 통합판 0.3.0-rc.24.3과 Chrome 확장 0.3.24입니다. 수정은 확장에도 포함되므로 기존 0.3.23만 계속 사용하면 적용되지 않습니다. ZIP의 README에 새 확장 적용과 연결 방법을 안내합니다. 같은 PC의 기존 계정·설정·원고·작업 기록은 그대로 사용하며 패치나 이전 EXE가 필요하지 않습니다.

회귀 테스트는 블로그 홈 복귀, 새 편집기 탭, 닫힌 로그인 탭, 남아 있는 이전 로그인 탭, 보안 확인·계정 불일치 차단, 기존 원고 보존과 반복 복귀 중단을 포함합니다. 실제 사용자 네이버 계정의 로그인이나 글 발행은 자동 테스트에서 수행하지 않습니다.
