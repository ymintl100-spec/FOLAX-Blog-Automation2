# FOLAX 0.3.0-rc.21 — 중복 소재 작성 허용

## 변경한 동작

기존 발행 글과 같은 소재·핵심 질문·제목이어도 새 원고를 작성합니다. 중복을 피하려고 다른 주제로 바꾸거나 검색·본문·이미지 생성을 생략하지 않습니다. 새 작업과 기존 작업 재개에 중복 소재 허용 기준을 적용합니다. Research의 novelty.duplicate:true는 참고 정보로 남을 수 있지만 작성 중단 사유로 사용하지 않습니다. 정확히 같은 제목이라는 이유로 본문 작성을 중단하던 검사도 생략합니다.

기존에 중복 판정 때문에 Research가 작성 기획과 근거 검토를 생략한 경우에는 해당 Research 응답을 한 번 다시 검토해 기획을 완성합니다. BLOCK/REVISION을 앱이 임의로 PASS로 바꾸지 않습니다. 실제 근거가 충분하고 기획이 완성된 PASS라면 중복 판정만으로 추가 모델 호출을 하지 않습니다. 중복 비교를 위한 과거 제목·주제 전체 목록도 AI 프롬프트에 보내지 않아 불필요한 비교 토큰을 줄입니다.

추천 화면의 ‘유사·기존 글 제외’는 기본 해제합니다. 유사·기존 표시 자체는 참고 정보로 유지하며 사용자가 원하면 목록 필터를 켤 수 있습니다. 이미 발행한 추천 주제를 다시 작성하면 별도 기획을 만들고 이전 발행 기획·원고·발행 기록을 유지합니다. 같은 키워드·링크 입력으로 다시 새 원고를 요청해도 이전 원고를 덮지 않고 별도 기획으로 진행합니다.

## 중복으로 중단된 작업 재개

1. 기존 FOLAX 앱을 완전히 종료합니다.
2. FOLAX-Topic-Reuse-Download.exe를 실행합니다.
3. 다운로드 폴더의 Naver-Blog-Automator-0.3.0-rc.21.exe를 실행하고 버전을 확인합니다.
4. 작업 이력에서 이번 중복 중단 작업의 ‘재시도’를 한 번 누릅니다.
5. ‘중복 소재 허용 · 저장된 조사·자료 재사용 후 작성 계속’ 안내를 확인합니다. 저장 자료를 재사용하며 필요한 기획·근거 판단만 완료합니다.
6. 검수 대기가 되면 새 원고·이미지를 확인하고 기존 승인 절차로 진행합니다.

같은 제목으로 완료된 별도의 작업 때문에 중단 작업의 재시도가 잘못 막히거나 다른 작업으로 연결되지 않도록 작업 ID와 재시도 계보로 구분합니다. 해당 작업 자체가 이미 완료됐거나 같은 작업의 후속 재시도가 완료된 경우에는 중복 실행을 방지합니다. 이미 발행한 동일 원고의 재발행·발행 결과 미확인 상태에서 자동 재발행·동시 작업 방지는 유지합니다. 새 소재 허용과 기존 원고의 중복 발행 방지는 별도로 처리합니다.

## 유지되는 기준과 데이터

기존 계정·설정·원고·이미지·작업 이력·승인·발행 기록은 초기화하지 않습니다. 배포 파일에는 사용자 데이터가 포함되지 않습니다. 새 원고는 입력 자료로 작성하고 다른 글의 문장이나 개인 경험을 복제하지 않으며 허구의 사실·경험을 추가하지 않습니다. 실제 근거 부족·사실 오류·주제 이탈·가독성 문제는 기존 기준으로 반려합니다.

공백 제외 1,500자 목표(1,400~1,600자 허용), 태그 15개, 핵심 문장 볼드, 이미지 사용 시 기본 최소 4장, 자동 재시도 합계 최대 5회를 유지합니다. 기존 작업은 저장된 분량·태그 기준을 유지합니다. 링크 중심 혼합 작성과 부족한 설명만 입력 키워드로 검색하는 기능도 유지합니다. 티스토리는 플랫폼 제한에 따라 앞 10개 태그를 전달합니다.

Chrome 확장 0.3.22는 변경하지 않았으므로 그대로 사용합니다. 새 PC에서는 함께 제공되는 BlogAuto-Extension-0.3.22.zip을 계속 보관할 폴더에 풀고 chrome://extensions → 개발자 모드 → 압축해제된 확장 프로그램 로드에서 manifest.json이 있는 extension 폴더를 선택한 뒤 연결합니다. 프로그램 다운로드만으로 기존 PC 데이터가 자동 이전되지는 않습니다.

## 검증

자동 테스트 226개 통과. 같은 소재·동일 제목 작성, novelty 누락 허용, 이전 중복 BLOCK 한 번 재검토, 실제 근거 부족은 중단, 조사 보강 후 중복 소재 작성, 같은 제목의 별도 작업과 재시도 계보 구분, 추천 주제 중복 작성, 기발행 기획 보존, 동일 입력의 별도 기획, 보류·동시 작업 방지를 확인했습니다. 기존 승인·중복 발행 방지·계정 격리·이미지 재개·원문 범위 검수 테스트도 통과했습니다.

격리된 실제 Electron 앱에서 ‘같은 제목으로 완료된 별도 작업’과 ‘이전 버전에서 중복으로 중단된 작업’을 함께 저장해 작업 이력 재시도를 실행했습니다. 저장된 중복 판정을 재검토하는 모의 Research 1회·Writer 1회·Main 1회로 같은 제목의 새 원고가 검수 대기까지 진행됐습니다. 허용 기준 인계, 과거 전체 제목 목록 제외, 이전 체크포인트·별도 완료 기록 보존, 1,500자·태그 15개·볼드·1/5 횟수·새로고침·중복 목록 필터 기본 해제를 확인했습니다. 유료 AI·실제 검색·계정 발행·Windows GUI 실행은 하지 않았습니다.

Windows x64 패키지의 소스·버전·확장·네이티브 모듈을 확인하고, 공개 다운로드 파일의 크기·SHA-256과 다운로드 도우미의 파일 조합·압축 해제 결과를 검증합니다.
