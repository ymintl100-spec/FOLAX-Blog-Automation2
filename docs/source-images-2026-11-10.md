기본 작성 요청과 링크 원본 이미지 참고

작성 요청이 빈 화면으로 시작하고 링크의 이미지는 생성 단계에 전달되지 않던 경로를 수정했습니다.

- 사용자가 제공한 4개 항목의 요청문을 세 작성 화면에 기본으로 채웁니다. 기본 문구는 1,225자이며 수정하거나 지우거나 추가 요청을 덧붙일 수 있습니다. 사용자가 비운 입력도 탭 전환으로 복원하지 않습니다. 기존 작업의 요청·원고는 자동으로 변경하지 않습니다.
- 입력 링크의 본문 이미지와 지연 로딩 원본을 수집합니다. 네이버 글 본문 안에서 이미지 후보를 찾고 메뉴·프로필·작은 장식 이미지와 중복 주소는 제외합니다. 본문 이미지가 없으면 공개 대표 이미지를 참고할 수 있습니다.
- 참고 이미지는 총 최대 6장입니다. 한 링크는 최대 6장, 두 링크는 각 최대 3장, 세 링크는 각 최대 2장을 준비합니다. 공개 PNG·JPEG·WebP만 사용하고 다운로드 크기·해상도를 제한합니다. 실패한 이미지 때문에 본문이나 작업을 중단하지 않습니다.
- 실제 참고 파일을 이미지 생성 호출에 첨부합니다. 제품 형태·색상·비율·사용 장면을 원본에서 확인하고 관련 장면을 새 이미지에 반영하도록 지시합니다. 사진·작성자 서명·워터마크·페이지 구성을 그대로 복제하지 않으며, 원본 참고 파일 자체나 동일 파일 복사본은 생성 결과로 통과시키지 않습니다. 잘못 반환된 항목만 다시 생성하도록 연결합니다.
- 참고 파일은 작업 폴더에 별도로 저장하고 체크포인트에 기록합니다. 재개할 때 해시를 확인해 재사용하며, 참고 파일은 새로 생성할 최소 4장에 포함하지 않습니다. 키워드만 입력하거나 이미지 생성을 끈 경우 링크 이미지 다운로드를 하지 않습니다. 별도 이미지 분석 AI 호출은 추가하지 않습니다.
- 링크 이미지가 비공개·차단·지원하지 않는 형식이거나 읽히지 않으면 이유를 로그로 안내하고 본문 설명으로 이미지를 생성합니다. 원본과 완전히 같은 제품 세부 묘사를 보장하는 기능은 아니며 생성기의 참조 기능과 결과에 따라 달라집니다.

태그 15개, 약 2,000자 권장 목표, 분량 차이만으로 중단하지 않는 정책, 기존 품질 보완 최대 5회는 유지합니다. 계정·설정·원고·기존 이미지·중단 작업 기록과 Chrome 확장 0.3.24는 보존합니다.

검증: 자동 테스트 307개 통과(실패·건너뜀 0). 실제 Electron 화면의 기본 문구, 수정·빈 입력 보존을 확인했습니다. 제공된 네이버 글의 저장된 본문 HTML에서 이미지 7개를 추출하고 실제 서버에서 6개를 다운로드·변환했습니다. 이미지 파일 첨부 인수는 모의 Codex 프로세스로 검증했습니다. 실제 AI 이미지 생성이나 네이버 발행은 수행하지 않았습니다.
