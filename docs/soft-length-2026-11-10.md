# rc.24.4 — 약 2000자 권장 목표

본문은 공백 제외 약 2000자를 목표로 작성합니다. 목표는 권장값이며 최소·최대 글자수의 필수 통과 범위가 아닙니다. 제목·참고자료·이미지 표식·URL은 제외하고 소제목과 링크 표시 문구는 포함하는 기존 계산 방식은 유지합니다.

분량이 부족하거나 조금 넘었다는 이유만으로 본문 보완·추가 검색·재시도·작업 중단을 하지 않습니다. 근거가 충분하면 필요한 방법·이유·조건을 자연스럽게 설명하고, 자료가 짧으면 근거 있는 핵심을 정리한 뒤 다음 단계로 진행합니다. 같은 말을 반복하거나 사실·경험을 만들어 글자수를 채우지 않습니다.

변경 경로

- 새 작성, 조사·작성·검수 프롬프트와 화면 안내를 같은 권장 정책으로 연결했습니다. 이미지 계획도 본문 분량 범위를 강제하지 않습니다.
- 코드의 글자수 필수 검사를 권장 정책에서 해제했습니다. 실제 분량은 계속 측정·표시합니다.
- AI가 명시적으로 분량만 지적했고 나머지 7개 내용 검수 항목이 모두 통과한 경우에만 해당 분량 판정을 안내로 분리합니다. 원래 판정과 지적은 lengthAdvisory에 보존합니다. 실제 원고·출처 인용, 입력 범위·형식·이미지·연관성 등의 독립 검사는 그대로 진행합니다. 사실성·자연스러움 등 다른 검수 항목이 실패하면 분량 정책으로 통과시키지 않습니다.
- 기존 원고의 AI 재검수·쉽게 다듬기에도 권장 정책을 사용합니다. 이전 원고·버전·계정·설정은 그대로 보존합니다.
- 과거 분량 기준으로 멈춘 작업을 새 앱에서 재시도하면 마지막 본문과 완료 자료를 재사용하고 현재 정책으로 다시 검수합니다. 이전 체크포인트·원본 검수 기록을 직접 수정하지 않습니다. 이미 본문 검수가 끝나 이미지 단계에 있는 작업은 저장 결과를 그대로 사용합니다.

태그 15개, 핵심 문장 볼드, 이미지 최소 4장 정책과 실제 품질 보완 최대 5회는 유지합니다. 빈 원고·실제 핵심 근거 부족·사실 오류·중복 설명·이미지 누락 등 다른 문제는 계속 검사하므로 분량 외의 사유로는 중단될 수 있습니다.

배포는 Windows 통합판 0.3.0-rc.24.4입니다. Chrome 확장은 이전 로그인 복구가 포함된 0.3.24로 같으며, 이미 사용 중이면 그대로 사용할 수 있습니다. 패치나 이전 실행파일은 필요하지 않습니다.

검증은 650·1500·2000·2600·4200자 본문의 분량 보완 없이 진행, 분량만 지적한 검수의 안내 처리와 실제 사실성 차단 유지, 1177자 구형 작업의 본문 재작성 없는 재검수 및 원본 기록 보존을 포함합니다. 실제 Electron 화면에서 분량 안내 두 곳과 작성 화면이 약 2000자 권장·분량 차이로 중단하지 않음으로 표시되는지도 확인했습니다. AI 응답은 모의 응답을 사용했으며 실제 블로그 발행은 수행하지 않았습니다.
