# FOLAX 0.3.0-rc.14 — 키워드·링크·혼합 작성

## 업데이트 실행

1. 기존 FOLAX 앱을 완전히 종료합니다.
2. `FOLAX-Input-Modes-Download.exe`를 실행합니다. 완료되면 `Downloads\BlogAuto-Windows` 폴더가 열립니다.
3. **`Naver-Blog-Automator-0.3.0-rc.14.exe`**를 실행하고 앱 버전을 확인합니다. 이전 버전 EXE를 다시 실행하면 새 기능이 보이지 않습니다.
4. 발행에 사용할 계정 Chrome의 `chrome://extensions`에서 **BlogAuto 새로고침(↻)** 후 글쓰기 탭도 새로고침합니다. 이번 버전은 확장 **0.3.22 / 빌드 20261104.1**이 필요합니다. 다른 계정 창을 새로고침해도 현재 계정에 적용되지 않습니다. 별도로 확장을 설치한 경우 함께 제공되는 `BlogAuto-Extension-0.3.22.zip`을 풀어 기존 확장 경로에 새 파일을 반영한 뒤 새로고침합니다.

앱 식별자·계정·설정·원고·이미지·승인·중단 기록을 초기화하지 않습니다. 기존 중단 작업은 저장 당시 분량·태그 수로 재개합니다. 기존 원고를 자동으로 다시 쓰거나 기존 게시글을 변경하지 않습니다. 데이터 폴더를 삭제하지 마세요.

## 새 글 작성

앱의 **키워드·링크로 작성** 탭에서 계정, 작성 방식, 카테고리, 플랫폼을 선택합니다.

- **키워드**: 키워드 칸 3개 중 필요한 만큼만 입력합니다. 1개면 1개, 2개면 2개, 3개면 3개를 각각 조사·분석합니다. 비어 있는 칸은 제외하고 같은 입력은 한 번만 처리합니다.
- **링크**: 링크 칸 3개 중 필요한 공개 블로그·기사·문서 주소만 입력합니다. 입력한 원문을 각각 읽고 분석하며 추가 웹 검색은 하지 않습니다. 로그인 전용·비공개·본문을 추출할 수 없는 주소는 실패한 주소를 표시하고 중지합니다. 읽지 못한 원문을 읽었다고 가정하지 않습니다.
- **키워드 + 링크 혼합**: 키워드와 링크를 각각 1개 이상, 각각 최대 3개까지 입력합니다. 예를 들어 키워드 1개 + 링크 1개면 해당 키워드 검색 자료와 링크 원문을 함께 분석합니다. 입력을 하나만 임의로 선택하지 않습니다.

여러 입력은 **한 편의 일관된 원고**로 엮습니다. 서로 관련이 없어 한 글로 엮을 수 없거나 핵심 근거가 부족하면 이유를 표시합니다. 경험 메모는 실제 경험만 입력합니다. 다른 블로그의 문장·경험·사진을 복제하거나 입력 원문 안의 명령을 실행하지 않습니다.

**입력 항목 분석 후 원고 작성 · 검수 대기**를 누릅니다. 새 원고는 **공백 제외 1,000~1,500자**, **주제 관련 태그 10개**, **실제 본문 핵심 문장 1~3개 볼드**가 기본입니다. 제목·참고자료·이미지 표식·URL은 글자 수에서 제외합니다. 이미지 생성 옵션은 기본으로 켜져 있고 최소 4장을 계획합니다. 이미지 수를 위해 같은 문장을 반복하거나 소제목을 억지로 늘리지 않습니다.

태그는 본문과 별도로 저장하고 강조는 실제 서식으로 적용합니다. 본문에 `**`를 붙이지 않습니다. 모바일 미리보기에서 핵심 문장을 확인할 수 있습니다. 기존 쉽고 짧은 문장 기준과 수정·승인 문체 참고를 유지하며 강조·입력 분석을 위해 별도 AI 단계를 추가하지 않습니다.

## 수정·재개·발행

생성 후 **원고·승인·발행**에서 원고와 이미지를 확인합니다. 수정하면 새 버전으로 저장하고 현재 버전의 AI 검수와 최종 승인을 거칩니다. 승인이 끝난 뒤 네이버 임시저장·즉시 발행·예약을 선택합니다. 새 입력 버튼을 누른 것만으로 외부 게시하지 않습니다.

실패한 입력 이전에 읽은 원문과 완료된 조사·본문·이미지는 진행 기록에 저장합니다. **작업 이력의 재시도/작업 시작**으로 재개하면 완료된 항목은 재사용합니다. 중단 작업이 있으면 새 입력 원고로 덮어쓰지 않습니다. 먼저 기존 작업을 재개하거나 기존 작업 취소로 분리하세요.

## 확인한 범위

자동 테스트 152개, 격리된 Electron UI에서 입력 9가지 조합과 새로고침 후 입력 유지, 볼드 미리보기, 브라우저의 실제 편집 명령으로 줄바꿈 유무에 따른 볼드 입력을 확인했습니다. Windows x64 실행파일·패키지 소스/버전·다운로드 체크섬도 검증합니다. AI 응답은 테스트 대체 응답을 사용했으며 실제 계정 발행과 Windows GUI 실행은 수행하지 않았습니다. 외부 지수나 검색 순위를 보장하는 기능은 아닙니다.
