# rc.24.2 문장·전개 개선

입력 링크: https://blog.naver.com/folaxhealth/224464500765

사용자가 제시한 생성 원고는 같은 조언을 여러 문단에서 풀어 쓰고, 사용법 뒤에 쉬운 단어의 정의와 추상적인 해설을 덧붙였습니다. 원문은 손으로 하는 방법, 매트 사용 순서, 고를 때 볼 점과 제품별 관리 내용을 다룹니다. 생성 글에서는 강도·접촉 위치·놓을 공간을 거듭 설명하면서 읽는 흐름이 늘어졌습니다.

## 변경 내용

- 조사 기획에서 발췌 전체를 읽고 서로 다른 정보를 답과 구성에 배치하도록 했습니다. 한 가지 조언의 재해석으로 분량을 확보하지 않습니다. 부족하면 기존 자료 수집 절차에 구체적인 질문을 넘깁니다. 키워드·혼합 방식은 원문 범위 안에서 보강하며, 링크 전용의 외부 검색 제한은 유지합니다.
- 모든 문단에 답·이유·선택 해설을 덧붙이던 작성 지침을 바꿨습니다. 순서는 순서로, 비교는 실제 차이로 바로 설명합니다. 쉬운 단어를 다시 정의하거나 앞 문장의 뜻만 해설하는 문장은 덜어냅니다. 같은 뜻의 문장이 멀리 떨어져 있어도 함께 정리합니다.
- 첫 작성과 부분 수정, 원고 화면의 ‘쉽게 다듬기’에 같은 문장 지침을 적용했습니다. 첫 응답 안에서 중복을 정리하고 실제 분량을 다시 확인하도록 했습니다.
- 검수에서는 의미가 겹치는 실제 두 구절을 짧게 짝지어 지적하도록 했습니다. 높은 연관성 점수만으로 가독성을 통과시키지 않습니다. 표현 하나를 금칙어로 삼거나 기계적인 반복 점수를 추가하지 않았습니다. 서로 다른 단계·대상·예외에 꼭 필요한 설명은 보존합니다.

새 AI 단계나 별도 문체 검수 호출은 추가하지 않았습니다. 공백 제외 1400~1600자, 태그 15개, 이미지 최소 4장 정책, 자동 보완 합계 최대 5회와 이전 rc.24.1의 문단 수정 한도 수정은 유지합니다. 근거 없는 효과·방법·횟수·경험으로 분량을 채우지 않습니다. 자료가 실제로 부족하면 이유를 표시합니다.

## 문장 수정 방향

아래는 문체를 설명하는 짧은 예시입니다. 1500자 완성 원고나 새 의학적 사실이 아니며, 사용자 승인 학습 예시로 자동 등록하지 않습니다.

수정 전: “체중 조절은 발에 싣는 몸의 무게를 바꿔 자극을 맞추는 거예요.”

수정 방향: “발을 천천히 올리고 편한 만큼만 체중을 실어 보세요.” 앞에 이미 이 사용법이 있으면 정의 문장을 삭제합니다.

수정 전: “원하는 부위와 실제로 닿는 위치를 연결해서 생각하면 선택 기준이 구체적이 돼요.”

수정 방향: “누르고 싶은 부위에 돌기가 닿는지 확인하세요.”

## 작은 패치 사용 방법

1. 기존 FOLAX 프로그램을 완전히 종료하세요.
2. FOLAX-rc24-Plain-Writing-Patch.exe를 다운로드하고 실행하세요. 약 183KB입니다. 패치 실행 중에는 인터넷에서 추가 파일을 내려받지 않습니다.
3. 파일 선택창에서 원래의 Naver-Blog-Automator-0.3.0-rc.24.exe를 선택하세요. rc.24.1을 사용 중이어도 이전 패치가 보존한 원본 rc.24 파일을 선택합니다. FOLAX-...-Download.exe 같은 다운로드 도구는 대상이 아닙니다.
4. 새 Naver-Blog-Automator-0.3.0-rc.24.2.exe를 저장할 위치를 확인하고, 완료 후 새 실행파일을 실행하세요. 원본을 덮어쓰지 않습니다.

기존 계정·설정·원고·이미지·작업 기록·확장 연결은 그대로 사용합니다. Chrome 확장은 0.3.23을 그대로 사용하며 이번 패치 때문에 다시 설치할 필요는 없습니다. 공식 rc.24 원본의 크기와 SHA-256이 일치하지 않으면 아무 파일도 수정하지 않고 중지합니다.

## 이미 만들어진 원고에 적용

새 작성부터 새 지침이 사용됩니다. 이미 저장되거나 발행된 글을 자동으로 변경하지 않습니다.

기존 글은 ‘원고’에서 해당 글을 열고 ‘현재 원고 쉽게 다듬기 · AI 1회’를 누르세요. 수정 전 버전은 보존하고 새 버전에 저장합니다. 결과를 직접 확인하고 ‘현재 버전 AI 검수 요청’ 후 다시 승인하세요. 이미 발행한 네이버 글은 이 동작으로 수정되지 않습니다.

쉽게 다듬기는 기존 자료로만 수정하며 추가 검색을 수행하지 않습니다. 중복을 없애면 1400자 아래가 되는데 보충할 자료가 없다면 원고를 보존하고 이유를 표시합니다. 키워드와 링크를 사용한 새 작성에서는 조사 단계부터 원문 안의 서로 다른 정보와 필요한 보강 질문을 기획합니다.

## 검증과 한계

자동 테스트 277개 통과. 저장 원고의 단일 Writer 호출·새 문장 지침 전달·1400~1600자 기준·태그/이미지/출처 보존·새 버전 저장과 승인 초기화, 이전 문단 한도 수정 및 최대 5회 보완 회귀를 확인했습니다.

실제 Electron 화면에서 ‘쉽게 다듬기’를 눌러 새 지침이 모델 입력에 들어가는지 확인했습니다. 테스트 결과는 1529자·태그 15개였으며 이전 버전과 이전 AI 검수 기록은 보존하고 새 버전에는 재검수와 승인이 필요함을 확인했습니다. AI 응답은 모의 응답이므로 실제 모델이 매번 같은 문장 품질을 낸다는 검증은 아닙니다.

Windows용 rc.24.2 EXE를 빌드하고 공식 rc.24 원본에 패치를 적용해 빌드 결과와 바이트 단위로 일치함을 확인했습니다. Windows GUI 파일 선택창과 실제 네이버 발행은 수행하지 않았습니다.
