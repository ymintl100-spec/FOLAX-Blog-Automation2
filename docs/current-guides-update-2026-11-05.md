# FOLAX 0.3.0-rc.17 — 분량 안내·AI 지침 일치 수정

## 확인한 문제와 수정

이미지 미리보기 안내와 문체 학습 안내에 이전 분량인 1,000~1,200자가 남아 있었습니다. 실제 새 글 검사는 1,400~1,600자였지만 AI에 전달하는 이미지 계획 지침에도 이전 범위가 남아 있어 함께 수정했습니다.

새 글의 실제 생성 설정과 화면 안내는 이제 같은 기본값을 읽습니다. 이미지 미리보기와 문체 학습 안내는 **“새 글은 공백 제외 1,500자 목표(1,400~1,600자 허용)입니다.”**로 표시합니다. 키워드·링크 작성 화면도 같은 설정에서 분량·태그·자동 재시도 안내를 가져옵니다.

이미지 계획 지침은 작업의 실제 분량 설정을 따릅니다. 새 작업에서는 Research·Writer·Main 모두 1,400~1,600자를 전달받고, 저장된 이전 작업은 해당 작업의 기존 글자 수 범위를 따릅니다. Image Worker는 본문을 다시 쓰지 않으며, 앱이 재시도를 관리한다는 안내도 실제 동작과 일치시켰습니다.

## 유지되는 기능과 데이터

새 글은 공백 제외 1,500자 목표·1,400~1,600자 허용, 태그 15개, 핵심 문장 볼드, 이미지 기본 최소 4장, 자동 재시도 최대 5회입니다. 상단 횟수·진행 막대와 작업 이력 기록도 유지합니다. 티스토리는 플랫폼 제한에 따라 태그 앞 10개를 전달합니다.

기존 계정·설정·원고·이미지·중단 기록·승인 상태는 초기화하지 않습니다. 기존 원고의 분량이나 태그를 자동 변경하거나 원고를 재생성하지 않습니다. 이미 게시된 글도 변경하지 않습니다.

## 실행 방법

1. 기존 FOLAX 앱을 완전히 종료합니다.
2. `FOLAX-Current-Guide-Download.exe`를 실행합니다.
3. 열린 다운로드 폴더에서 **Naver-Blog-Automator-0.3.0-rc.17.exe**를 실행합니다.
4. 이미지 미리보기 아래 안내가 1,500자 목표·1,400~1,600자로 표시되는지 확인합니다. 앱 버전도 0.3.0-rc.17인지 확인하세요.

Chrome 확장 **0.3.22는 그대로 사용**합니다. 새 컴퓨터라면 함께 제공되는 `BlogAuto-Extension-0.3.22.zip`을 계속 보관할 폴더에 풀고, Chrome `chrome://extensions` → 개발자 모드 → 압축해제된 확장 프로그램 로드에서 `manifest.json`이 있는 `extension` 폴더를 선택합니다. 해당 계정 Chrome과 앱을 연결하고 로그인하세요. 확장 폴더를 삭제하거나 옮기지 마세요.

## 확인한 범위

자동 테스트 **182개** 통과. 새 Research·Writer·Main의 이미지 계획에 이전 1,000~1,200자 지침이 섞이지 않는 것과, 이전 작업의 1,000~1,200자·1,000~1,500자 정책 유지 여부를 확인했습니다. 기존 자동 재시도 5회·태그 15개·데이터 보존 테스트도 통과했습니다.

격리된 Electron 앱에서 실제 이미지 미리보기·문체 학습 안내 두 곳과 키워드·링크 작성 화면이 같은 설정의 1,500자 목표·1,400~1,600자 허용·태그 15개·자동 재시도 5회를 표시하는지 확인했습니다. 유료 AI 호출이나 실제 계정 발행은 하지 않았습니다. Windows x64 빌드·패키지 소스·공개 다운로드 체크섬도 검증합니다. 실제 Windows GUI 실행은 수행하지 않았습니다.
