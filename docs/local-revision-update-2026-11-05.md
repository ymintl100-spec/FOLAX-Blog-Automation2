# FOLAX 0.3.0-rc.18 — 부분 수정 응답 연결·반복 실패 수정

## 로그에서 확인한 문제

첨부 로그의 본문은 공백 제외 1,427자, 태그 15개로 현재 기준을 통과했고, 내부 연관성도 100/100이었습니다. 그러나 반복·추상적인 문장에 대한 부분 수정 응답이 다섯 번 연속 거부됐습니다. 이전 코드는 수정 불가(status:failed)와 원고 식별값 누락·불일치를 같은 오류로 표시했으므로, 로그만으로 어느 필드가 실패했는지는 확정할 수 없습니다.

## 수정한 동작

부분 수정은 이제 p1, p2 같은 문단 번호를 사용합니다. 모델이 긴 해시나 원문 구절을 그대로 복사할 필요가 없습니다. 앱이 수정 요청 당시의 원고·태그·이미지 계획·파일 경로를 연결해 보관하고 응답 적용 전에 대조합니다. 다른 원고의 캐시, 변경된 원고, 없는 문단, 겹친 수정, 소제목·이미지 마커 변경은 거부합니다. 수정하지 않은 문단과 제목·출처·이미지 경로는 보존합니다. 이전 형식의 정확한 before/after 응답도 앱이 요청 원고를 확인한 경우에만 적용합니다.

응답 형식 오류와 실제 수정 불가를 구분해 구체적인 이유를 표시합니다. 같은 응답 형식 오류가 두 번 연속 발생하면 나머지 자동 호출을 중지하고 원고를 보존합니다. 모델이 근거 부족 등으로 수정할 수 없다고 답하면 해당 이유와 함께 중지합니다. 내용 보완은 기존 합계 최대 5회 자동 재시도 규칙과 횟수 표시를 따릅니다. 검수 탈락을 통과로 바꾸거나 분량·정확성 기준을 낮추지 않습니다.

수정 요청에는 해당 작업의 현재 글자 수와 늘리거나 줄일 수 있는 범위를 전달합니다. 중복을 덜면서도 기존 자료 안의 필요한 차이·조건을 구체적으로 쓰도록 안내합니다. 원고 전체를 중복 전송하지 않고 문단 문서를 한 번 전달합니다. 새 근거·경험·효과·횟수를 만들어 분량을 채우지 않도록 유지합니다.

새 작업은 공백 제외 1,500자 목표(1,400~1,600자 허용), 태그 15개, 핵심 문장 볼드, 이미지 사용 시 기본 최소 4장을 유지합니다. 기존 작업은 저장된 분량·태그 정책을 그대로 사용합니다. 티스토리는 플랫폼 제한에 따라 앞 10개 태그를 전달합니다.

## 실행 및 중단 원고 재사용

1. 기존 FOLAX 앱을 완전히 종료합니다.
2. FOLAX-Revision-Link-Download.exe를 실행합니다.
3. 다운로드 폴더의 Naver-Blog-Automator-0.3.0-rc.18.exe를 실행하고 앱 버전을 확인합니다.
4. 작업 이력에서 실패한 해당 작업의 ‘재시도’를 한 번 누릅니다. 완료된 조사·원고와 검수 지침을 재사용하고, 수정 응답을 다시 받습니다. 상단 자동 재시도 횟수를 확인하세요.
5. 검수 대기 상태가 되면 실제 원고·이미지를 확인하고 기존 승인 절차로 진행합니다.

기존 계정·설정·원고·이미지·중단 기록·승인 상태는 초기화하지 않습니다. 배포 파일에는 사용자 데이터가 포함되지 않습니다. 다른 PC에서 실행하는 것만으로 기존 PC 데이터가 자동 이전되지는 않습니다. 실제 발행은 자동 검증 중 실행하지 않습니다.

Chrome 확장 0.3.22는 변경하지 않았으므로 같은 PC에서는 그대로 사용합니다. 새 PC는 함께 제공되는 BlogAuto-Extension-0.3.22.zip을 계속 보관할 폴더에 풀고 Chrome의 chrome://extensions → 개발자 모드 → 압축해제된 확장 프로그램 로드에서 manifest.json이 있는 extension 폴더를 선택한 뒤 계정 창과 연결합니다.

## 검증 범위

자동 테스트 192개 통과. 해시 없는 문단 응답의 정상 적용, CRLF·이모지·동일 문장 구분, 다른 원고·이미지 경로·캐시 거부, 수정 불가 이유 보존, 동일 응답 형식 오류 두 번 후 중지, 이전 데이터·분량·태그·최대 5회 보완 규칙을 확인했습니다.

격리된 실제 Electron 앱에서 이전 버전 형식의 저장된 1,427자 원고를 작업 이력 재시도로 불러와 모의 CLI의 해시 없는 문단 응답을 적용했습니다. 새 조사·전체 Writer 호출 없이 부분 수정 1회와 Main 검수만 실행해 검수 대기까지 진행했으며, 태그 15개·볼드·1/5 표시·재시작 후 횟수 유지·원래 체크포인트 보존을 확인했습니다. 유료 AI 호출·실계정 발행·Windows GUI 실행은 수행하지 않았습니다.

Windows x64 빌드에 최신 소스와 확장 0.3.22가 포함되는지 확인하고, 공개 배포 파일의 크기·SHA-256과 다운로드 도우미의 조합·압축 해제 결과를 검증합니다.
