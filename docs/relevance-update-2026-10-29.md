# FOLAX 0.3.0-rc.10 — 제목·본문·태그·이미지 설명의 연관성 강화

NDEX 분석 화면과 실제 예시 글을 비교해 주제의 연결을 강화했습니다. NDEX 외부 점수를 임의로 만들어 표시하지 않습니다. 기존 조사·Writer·최종 Main 검수 안에서 계획과 실제 인용 근거를 확인하고, 새 글은 공개된 앱 내부 점검 95점 이상을 목표로 합니다. 외부 점수·포스팅 지수·검색 순위가 오른다는 보장은 없습니다.

## 확인한 자료와 해석

- 제공된 첫 분석: 연관성 58.0, 키워드 일치 20/40, 반복 빈도 23/30, 제목 길이 15/15, 의미 연관 0/15.
- 제공된 비교 분석: 연관성 83.3, 키워드 일치 23.3/40, 반복 빈도 30/30, 제목 길이 15/15, 의미 연관 15/15. 차이 25.3점 중 의미 연관 차이가 15점입니다. 두 자료만으로 네이버 순위와의 인과관계를 단정하지 않습니다.
- https://www.ndex.kr/post 의 공개 화면은 포스팅 URL을 입력해 분석하는 방식입니다. 살펴본 공개 페이지에서 세부 계산식은 확인하지 못했습니다. 외부 결과를 자동 조회·변경하거나 유료 분석을 실행하지 않았습니다.
- https://blog.naver.com/folaxhealth/224446621995 의 공개 본문을 읽었습니다. 제목과 보이지 않는 빈 문단을 제외한 HTML 텍스트는 공백 제외 921자, 문단 25개이며 ‘종아리’ 13회·‘스트레칭’ 16회·‘발목’ 7회로 집계했습니다. 이미지 속 글자는 제외했습니다. 이것은 앱의 단순 텍스트 집계이며 NDEX의 형태소·반복 계산식과 같다는 뜻이 아닙니다. 화면의 54회를 핵심어 하나의 목표 반복 횟수로 쓰지 않습니다.
- 글은 생활 상황에서 시작해 자세·움직임·발목·경사대 사용 조건으로 연결합니다. 그 연결 방식을 참고하며 문장·사진·제품 홍보·의학적 주장 자체를 복제하지 않습니다. 두 예시 모두 제목 길이가 만점이므로 제목이나 본문을 억지로 늘리지 않습니다.

## 생성·검수 변경

1. 기존 Research 응답에서 실제 제목의 짧은 핵심어와 질문에 필요한 관련 개념 1~5개를 계획합니다. 근거가 충분하면 3~5개를 선택하며 개수 때문에 무관한 개념을 만들지 않습니다. 추가 검색·기획 호출을 하지 않습니다.
2. Writer는 제목의 핵심어를 도입에 자연스럽게 연결하고 제목의 질문에 답합니다. 관련 개념을 단어 나열로 끝내지 않고 원리·조건·선택 기준으로 설명합니다. 태그 30개와 이미지 설명도 같은 질문·조건에 맞춥니다.
3. 기존 최종 Main 검수에서 답변·관련 개념·태그·각 이미지 설명의 실제 원고 인용을 반환합니다. 앱은 인용이 현재 본문/태그/이미지 설명에 실제 존재하는지 검사합니다. 이미지 항목은 계획·설명 대조이며 실제 픽셀을 보았다고 처리하지 않습니다.
4. 근거가 없거나 잘못된 인용은 미측정으로 표시하고 본문을 보존합니다. 실행 응답 문제의 재시도는 완료된 조사·본문을 재사용하고 Main만 다시 요청합니다. 실제 연관성이 부족하면 기존 한 차례 Writer 수정에 구체적인 보완을 묶고, 다시 통과하지 못하면 중지합니다. 점수 때문에 전체 주제 재탐색·무한 수정·별도 SEO 모델을 호출하지 않습니다.

## 앱 내부 점검 배점

이 배점은 NDEX의 계산식이 아닙니다.

| 항목 | 배점 | 확인 방법 |
|---|---:|---|
| 핵심어 배치 | 25 | 실제 제목 15점, 본문 초반 300자 10점. 띄어쓰기·기호 정규화 |
| 질문·답 일치 | 25 | 실제 답변 인용과 Main의 의미 판단 |
| 관련 개념 설명 | 20 | 계획 개념별 실제 설명 인용과 관련성 판정 비율 |
| 태그 정합 | 10 | 전체 태그의 의미 판단 및 실제 태그/본문 예시 대조 |
| 이미지 설명 정합 | 10 | 모든 이미지 계획의 실제 설명/본문 인용 대조 |
| 자연스러운 사용 | 10 | Main의 문맥 판단, 키워드 나열·과도한 문자 점유 점검(정규화 본문에서 핵심어 문자의 합이 20% 초과하거나 3회 연속 나열한 경우 과다 신호. 앱의 휴리스틱이며 NDEX 기준이 아님) |

모든 적용 항목의 근거가 있어야 총점을 표시합니다. 근거가 없는 의미 항목을 0점이나 만점으로 대신하지 않습니다. 이미지 없는 원고는 해당 항목을 제외한 90점 배점을 100점 기준으로 환산하며 측정 배점을 함께 표시합니다. 핵심어 언급 수·제목 길이는 실제 관측값으로 표시하며 특정 횟수나 제목 길이를 억지로 맞추지 않습니다. 의미 판정은 AI의 판단이며 인용 검사가 사실·의미의 정확성을 독립적으로 보장하지 않습니다.

## 화면과 기존 글

- 생성 미리보기와 ‘원고·승인·발행’ 화면에 내부 점수, 항목 배점, 측정 상태, 실제 관련 개념 인용, 보완 항목을 표시합니다. NDEX 점수는 직접 확인 전 ‘미측정’입니다.
- 기존 저장 원고는 ‘연관성 포함 AI 검수’를 눌러 현재 버전을 한 번의 Main 검수로 분석할 수 있습니다. 본문을 자동으로 고치지 않으며 해당 검수 후에는 다시 최종 승인합니다. NDEX 버튼은 공식 분석 화면을 열고 자동 제출하지 않습니다.
- 제목/본문을 편집 중이면 이전 점수를 숨깁니다. 저장한 새 버전에도 과거 버전의 의미 근거를 재사용하지 않습니다. 태그·이미지 설명이 바뀌어 인용이 일치하지 않아도 미측정으로 처리합니다.
- 기존 계정·설정·원고·이력·중단 작업 파일을 삭제하거나 초기화하지 않습니다. 기존 체크포인트는 저장 당시 설정으로 재개하며 새 연관성 통과 조건을 소급 적용하지 않습니다.
- 본문 1,000~1,200자·최소 이미지 4장·태그 30개·참고자료/운영사 문구 제거·이미지 배치 보완·기존 최종 승인 절차를 유지합니다.

## 실행

기존 앱 완전 종료 → `FOLAX-Relevance-Download.exe` 실행 → `다운로드\BlogAuto-Windows\Naver-Blog-Automator-0.3.0-rc.10.exe` 실행. 새 글부터 강화한 생성·검수 기준이 적용됩니다. 기존 글은 원고 화면에서 연관성 포함 검수를 선택하세요. 이미 0.3.21인 Chrome 확장은 갱신하지 않아도 됩니다.

## 검증

자동 테스트 128개 통과. 미측정과 실제 점수 구분, 가짜/중복 인용 거절, 모든 이미지 설명 대조, 실제 보완 필요 시 점수 하락, 키워드 나열로 만점 불가, 기존 세 호출 유지, 잘못된 근거 응답에서 Main만 재개, 기존 한 차례 수정 한도, 이전 체크포인트 보존, 수정 후 오래된 점수 제거, 원고를 바꾸지 않는 명시적 분석을 확인했습니다. 1,000~1,200자·4장 이미지·태그 30개와 연관성 결과의 체크포인트 재개도 통합 검증했습니다.

격리된 Electron UI에서 미측정 → 한 번의 대체 Main 검수 → 내부 점수 표시, NDEX 미측정 표시, 편집 시 점수 숨김과 렌더러 오류 0건을 확인했습니다. 모델·발행 응답은 테스트용 대체 응답입니다. 실제 유료 AI, Windows GUI 실행, NDEX 재분석, 로그인 계정 발행을 실행하지 않았습니다. Windows x64 빌드·패키지 소스·다운로드 체크섬을 확인합니다.
