# 네이버 블로그 자동화

Google Chrome 확장프로그램과 Codex CLI로 네이버·티스토리 글 생성 및 발행을 관리하는 Electron 앱입니다. 로그인은 사용자가 Chrome에서 직접 진행합니다.

## 실행

Node.js 24 이상, Google Chrome, 로그인된 Codex CLI가 필요합니다.

```sh
npm ci
npm start
```

개발 데이터는 기존 `runtime` 폴더에 저장됩니다. 업데이트 시 이 폴더를 유지하세요. 배포판은 OS의 앱 사용자 데이터 폴더를 사용합니다.

## 최초 연결

1. 앱에서 블로그 ID를 등록하고 **블로그 열기 / 로그인**을 실행합니다.
2. **크롬 확장 설치 → 설치 폴더 준비**로 확장 경로를 확인합니다.
3. 해당 Chrome의 `chrome://extensions`에서 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드합니다**로 폴더를 선택합니다.
4. 앱의 **확장프로그램 연결** 코드를 확장에 입력합니다.

계정별 Chrome마다 최초 연결이 필요합니다. 티스토리를 사용하면 공용 Chrome에도 로그인·연결하세요. 확장 업데이트 후에는 설치 폴더를 준비하고 확장 관리 화면에서 새로고침합니다.

## 건강 정보와 일상·경험을 함께 운영하기

[40편 분석 보고서](docs/blog-benchmark-2026-10-23.md)와 [표본별 관찰 자료](docs/blog-benchmark-samples.json)에 참고한 주소, 유형, 문장 전개, 줄·문단·이미지 배치와 반영 기준을 기록했습니다. 원문 전문과 사진은 앱이나 문체 학습에 넣지 않습니다.

형식 v3는 **자동 / 건강 설명 / 실행·루틴 / 선택·비교 / 일상·경험**을 구분합니다. 자동은 기존 조사 응답에서 글의 역할과 전환점을 고릅니다. 설명형은 상황에서 오해와 선택 기준으로, 실행형은 준비와 실제 순서로, 비교형은 같은 기준의 차이로, 일상형은 장면·선택·변화·여운으로 전개합니다. 일상형에는 소제목 최소 개수나 정보 글의 1,800자 최소 분량을 강제하지 않습니다.

본문 아래 **내 글 문체 학습**에서 계정별 운영 방향과 형식을 저장합니다. **이번 글의 실제 경험 메모**는 해당 계정의 다음 새 작업 한 번에 사용합니다. 메모가 없으면 자동 형식은 정보형을 선택하고, 일상형을 직접 선택하면 경험 입력을 안내합니다. 생성 시작 전에 경험 메모를 재개 기록에 저장하고 입력칸을 비웁니다. 계정을 바꾸면 다른 계정에 메모를 전달하지 않습니다. 학습 예시 안의 경험은 새 글의 사실 자료로 사용하지 않습니다.

문체는 **원고 불러오기 → 직접 수정 → 승인 체크 → 수정본 승인·학습**으로 저장합니다. 최종 예시와 승인 해시·짧은 비교 발췌를 계정별 로컬 `runtime/writing-memory`에 최대 12개 보관합니다. 직접 승인한 표현·줄바꿈·문단 재구성을 참고하며, 승인 이력이 없는 이전 예시는 보관만 합니다. 삭제·적용 해제·피할 표현 설정을 지원합니다. 예시의 첫 부분뿐 아니라 수정된 중간·후반과 마무리도 짧게 참고하고, 승인 글에서 줄·문단의 대표 길이를 계산합니다. 모델 자체 재훈련은 없으며 전달하는 문체 지침은 2,500자 이내로 제한합니다. 편집한 학습 예시는 현재 발행 원고를 바꾸지 않습니다.

**모바일 형식 보기**에서는 실제 원고의 줄바꿈, 정렬, 소제목, 이미지 위치를 확인할 수 있습니다. **원고 텍스트 보기**로 원문을 확인합니다. 짧은 줄·문단 조정은 공백만 바꾸며 본문 내용·숫자·단위·참고 링크를 보존합니다. 확장과 미리보기는 같은 입력 계획을 사용합니다. v3는 본문 안에 제목을 다시 넣지 않으며, 설명/일상과 실행형에 따라 대표 이미지 위치를 달리하고 본문 이미지의 원고 순서를 유지합니다. 이미지 생성 수는 사용자 설정을 늘리지 않습니다.

Windows 앱 0.2.7-rc.1에는 확장 **0.3.18 / 편집기 빌드 20261023.2**가 포함됩니다. 앱이 시작될 때 기존 설치 준비 폴더를 최신 파일로 동기화합니다. 해당 계정 Chrome의 `chrome://extensions`에서 BlogAuto를 새로고침하세요. 계속 이전 버전이면 앱의 **확장 설치 → 설치 폴더 준비**에 표시된 폴더를 다시 로드합니다. 재개 중인 기존 글은 원래 설정을 유지하므로 새 형식으로 작성하려면 기존 작업을 취소하고 새 글을 시작합니다. 취소한 원고는 보관합니다.

기본 토큰 절약 모드는 기존 조사·Writer 자체 다듬기·최종 검수 3단계에서 형식·사실·자연스러움을 함께 다룹니다. 글의 역할 선정이나 학습을 위한 추가 AI 호출은 없습니다. 실제 도입·전환·마무리 인용으로 검수하고 보완은 최대 한 번으로 묶습니다. 테스트는 `npm test`로 실행합니다. Windows 네이티브 실행, 실제 네이버 편집기의 정렬·소제목 도구와 유료 모델 생성은 별도 실제 환경 검증이 필요합니다. 형식 유사성이나 검색 순위는 보장하지 않습니다.

## 배포

```sh
npm run dist           # Windows 휴대용 EXE: Windows에서 실행
npm run dist:mac:arm64 # Apple Silicon DMG: macOS에서 실행
npm run dist:mac:x64   # Intel DMG: macOS에서 실행
```

결과물은 `dist`에 생성되며 테스트·개인 데이터는 제외합니다. macOS에서는 `npm ci`를 새로 실행하세요. macOS 대응은 코드·모의 환경을 검증했으며 실제 Mac 실행·설치는 미검증입니다. 코드 서명·공증은 별도 설정이 필요합니다.
